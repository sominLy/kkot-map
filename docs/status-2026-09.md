## 이번 업데이트

### 1. 단풍 시즌 전환

- `seasons.is_active`를 단풍·은행으로 옮긴다.
- 9월 말은 아직 물드는 중이라 운영자 시드의 상태를 `blooming`(물드는 중)으로 바꾼다.
- 단풍 시즌에는 문구가 바뀐다: 피는 중/만개/졌어요 → **물드는 중/절정/낙엽 졌어요**, 투표는 "아직 고와요/다 떨어졌어요".
- 단풍 제보에 남아 있던 블로그·기사 링크는 지운다(인스타만 남김).

### 2. 인스타그램 단풍 명소 수집

**기준**

- 인스타그램 게시물만 쓴다(블로그·기사 제외).
- 기간: **2025년은 10월 게시물**, **2026년은 9월 넷째 주(9/21)부터**.
- 한 명소에 게시물이 여럿이면 기간 안에서 가장 최근 것을 쓴다.

**게시일 확인 방법**

인스타 게시물 주소의 shortcode는 미디어 ID를 base64로 적은 것이고, 미디어 ID의 상위 비트가 업로드 시각이다. 그래서 인스타에 접속하지 않고도 초 단위 게시 시각을 계산할 수 있다(`seed/instagram-autumn.mjs`의 `postedDate`). 캡션에 날짜가 적힌 게시물 7개로 검증했고 모두 일치했다(예: "2025년 10월 24일 원주 반계리 은행나무" → 2025-10-24).

### 3. 출처·저작권 원칙

- 게시물의 **사진과 글은 가져오지 않고 원문 링크만 저장**한다.
- 명소 설명은 게시물 문구를 옮기지 않고 직접 쓴 일반 정보다.
- 명소 상세에 "꽃맵은 원문 링크만 연결해요. 사진과 글의 권리는 게시자에게 있어요."를 표시한다.
- 게시자가 **링크 삭제를 요청**하면 `flags` 테이블에 `reason = 'source-removal'`로 쌓인다. 운영자가 확인 후 `source_url`을 비운다.

### 4. 게시일 표시

채용 공고 모음 사이트처럼 **절대 날짜와 상대 시간**을 함께 보여준다.

- 인스타 출처: `2025.10.29 게시 · 11개월 전`
- 사용자 제보: `2일 전 제보` (운영자 시드에는 표시하지 않음)
- 기존에 연결한 다른 꽃의 인스타 링크도 게시일을 채운다(`source_posted_at`).

### 5. 24절기 확장

- 절기마다 한자, 이름 풀이, 태양 황경, 한 줄 설명, **제철 음식, 해보면 좋은 일, 속담**, 그 무렵 피는 꽃(꽃맵 도감 데이터)을 넣었다.
- 음식·할 일·속담은 **2024년 이후 게시된 기사·글에서만** 모았고, 절기마다 출처 링크를 남겼다(`lib/content.ts`의 `SOLAR_TERMS[].sources`).
- 도감 탭: 지금 절기 카드(다음 절기까지 진행 바) + 봄·여름·가을·겨울 탭으로 펼쳐 보는 24절기 목록.

## Supabase 적용 방법

- **이미 운영 중인 DB**: SQL Editor에서 `supabase/autumn-2026.sql`만 실행하면 된다. 중복 실행해도 안전하다.
- **새로 세팅**: `schema.sql` → `RUN_ME.sql` → `instagram-links.sql` → `autumn-2026.sql` 순서.
- **인스타 게시물 추가**: `seed/instagram-autumn.mjs`의 후보 목록에 URL을 넣고 `node seed/instagram-autumn.mjs` → 생성된 SQL 재실행.
